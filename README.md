# SportsChud

Live game alerts for the NFL, NCAA football (FBS), NHL, MLB and NBA, as a Windows desktop app.

## Run it
Double-click `Start-SportsChud.bat`. On first run it calls `Setup-SportsChud.bat`, which installs Node.js and the app's dependencies, then opens the app. If something breaks, run `Setup-SportsChud.bat repair` to reinstall from scratch. On its first start the app itself adds a **SportsChud** shortcut with its icon to your desktop (only once; delete it and it stays gone). After that, use the desktop shortcut.

Node.js is installed with winget when available. On Windows editions without winget (such as Windows 10/11 LTSC), setup downloads a portable copy of Node.js into a `.node` folder next to the app instead, with no installer and no admin rights needed. Delete `.node` to remove it.

The icon lives in `assets/` (`icon.png` is the source; `icon.ico` is rendered from it). `renderer/icon.png` is the same logo for the sidebar.

Version: see `package.json` (shown in Settings). Bump it each release; the zip is named `SportsChud-vX.Y.Z.zip`.

Manual route: install Node.js 18+, then `npm install` and `npm start` in this folder.

## Build an installer
`npm run dist` builds on Windows. Or push this folder to GitHub and run the "Build Windows installer" workflow.

The installer (`SportsChud-Setup.exe`) lets you pick the folder and installs to `C:\Program Files\SportsChud` by default (needs administrator permission). It bundles everything, so Node.js is not needed.

## Release and install from GitHub
1. Set `version` in `package.json`, commit and push.
2. Tag it and push the tag, e.g. `v0.3.4`. GitHub Desktop: History tab, right-click the commit, Create Tag. Then Push origin.
3. The workflow builds the installer and attaches `SportsChud-Setup.exe` to a GitHub Release.
4. On any PC, run `Install-SportsChud.ps1`. It downloads the latest release and installs it silently to Program Files. (The GitHub `username/repository` is set at the top of that file and in `updater.js`; change both if the account or repo is renamed.)

The tag must match `version` in `package.json` (for example tag `v0.4.1` for version `0.4.1`). The build fails on purpose if they differ.

## Updates
The installed app checks GitHub for a newer release 20 seconds after it starts and then every 6 hours. When one exists you get a notification, a banner under the title bar, and an **Install update** button in Settings. Clicking it downloads `SportsChud-Setup.exe` (to a temporary name, so a half-finished file can never be run), checks that it is a complete, real installer (including GitHub's SHA-256 checksum when GitHub provides one) and then opens it; Windows asks for administrator permission, since the app lives in Program Files. SportsChud keeps running while the installer opens and does not close itself. Once the installer is open, closing SportsChud's window or choosing Quit really quits it (window, tray icon, mini scoreboard, background polling), so nothing is left running for the installer to trip over; the installer may also offer to close SportsChud itself. If you decline the permission prompt, **Open installer again** in Settings reopens the same download. If the download is bad, nothing is opened and SportsChud tells you. It never installs anything on its own. Turn the automatic check off in Settings with **Check for updates automatically**; **Check now** still works. Updates only apply to the installed app, not to a copy run from source with the `.bat` files. Versions before 0.4.0 can't update themselves, so install 0.4.0 by hand once.

## How it works
- **Standings** shows every league's table (conferences for NHL/NBA, divisions for MLB/NFL) with your followed teams highlighted and clinch markers (x, y, z, e) where ESPN provides them.
- **Playoffs** lists every series in a league's postseason with the series score, live game or next game time, and your teams first. By default the tab only appears while one of your teams is still alive in a postseason (it hides if they missed the playoffs or were eliminated); turn off **Autohide Playoffs** in Settings to always show it. All the autohide switches (Playoffs, Activity, out of season sports, teams that are out, Mini scoreboard) sit together under **Autohide** in Settings.
- **Scores** and **Recaps** are grouped by team by default; the **By team / By status** pills in the header switch it. All pills live in the header on the same line as the title: on the left the league or team picker (Teams, Standings, Roster, Injuries), then a `|`, then the option pills (By team / By status, Injuries' My teams / Whole league, Schedules' Day / Week / Month). On the right: the blue subtitle, a `|`, then the category name.
- **Roster** shows the full roster of any team you follow, grouped by position or unit, with a player search, jersey, age, size, experience and an injury badge. Click a player's name to open their ESPN page.
- **Injuries** shows the league injury report with status (Out, Day-To-Day, IR), injury type, expected return date and ESPN's note. Switch between **My teams** and **Whole league**; your teams are listed first and tagged.
- **Scores** shows live and today's games with the current period, inning or quarter. **Schedules** is a monthly calendar of games for every team you follow. **Teams** is where you pick teams and set alerts. **Activity** logs every alert sent (by default the tab only appears once the first alert has gone out; turn off **Autohide Activity** in Settings to always show it).
- The sidebar is split into **Games** (Scores, Recaps, Activity), **Stats** (Standings, Playoffs, Leaders, Pickups, Injuries) and **Teams** (Schedules, Roster, Select) with yellow dividers; the lock button at the bottom lets you reorder items within their group.
- Click a player's name in **Roster**, **Injuries**, **Leaders** or a game's box score to see their bio and season stats from ESPN in a panel.
- **Schedules** reopens in the Day, Week or Month view you used last.
- Pick teams on the **Select** tab. Each team has its own toggles: reminder, game start, periods/innings/quarters, scoring, close game, overtime, final.
- Leagues you don't follow any team in are left out of the Standings and Injuries league pickers. Only the Select tab always lists every league, so you can add a first team.
- Two separate switches under **Autohide** in Settings, both **on by default**, take things out of **Scores, Recaps, Standings, Schedules and Injuries**. **Roster** and the **Teams** tab are never affected (Teams has to list everything so you can follow and unfollow), and alerts for your teams keep working either way. Nothing is hidden until SportsChud knows the answer, or if ESPN can't be reached.
  - **Autohide out of season sports** is about the whole sport. When its season and playoffs are over (no games in the last couple of days or the next ~10 days), that sport and your teams in it disappear from those sections. It comes back on its own when games return.
  - **Autohide teams that are out** is about one team. When a team you follow is out of the season or the playoffs, it disappears from those sections; if it was your only team in that sport, the sport goes too, otherwise the sport stays for your other teams. A team counts as out when it lost its latest playoff series (or single playoff game), ESPN marks it eliminated (the `e` in Standings), or, in the NHL and NBA, the playoffs have been underway for a few days and it never played in them. MLB, the NFL and college football give top seeds byes, so a team that hasn't played yet there is never treated as out. If SportsChud can't tell, the team is shown.
  - If every team you follow is hidden, those sections show a short "Nothing to show right now" note with a button to Settings.
- **Show "Send test alert" button** (Settings, off by default) puts the Send test alert button back at the bottom of the sidebar, for checking that Windows notifications work.
- The taskbar, title bar, tray and notifications use the SportsChud icon, not Electron's. The installed `SportsChud.exe` now has the icon built in, and the running window uses an on-disk copy of it.
- **Close game** alerts once per game when it is late and tight: NHL 3rd period with 10:00 left or less and within a goal, NBA 4th quarter with 5:00 left or less and within 5, NFL and NCAAF 4th quarter with 5:00 left or less and within 8, MLB 8th inning or later and within a run. A tied game in those windows reads "Tied late".
- **Overtime** alerts when a game enters overtime, a shootout, extra innings or a further overtime period. It replaces the "Periods" alert for that moment so you don't get two.
- **Standings** alerts (a per-team toggle, on by default) tell you when a finished game moved your team in the standings: a new rank in its division or conference, or a clinch marker (x, y, z, e). ESPN's standings lag a final by a few minutes, so SportsChud waits until your team's record updates (checking for up to about 90 minutes), then sends one alert only if something actually changed, for example "Moved up to 2nd in Atlantic (was 3rd)". It stays quiet in the playoffs. Your tables are compared the same way the Standings tab shows them.
- **Mini scoreboard** (Settings, off by default, or the tray menu's **Mini scoreboard** checkbox) is a small always-on-top window that lists only your live games, with each team's score and the period and clock. It uses the same charcoal, text and live colors as the app, with a glass card per game that glows in the two teams' colors. It floats above other windows without taking focus and has no taskbar button. Drag it anywhere, and drag any edge or corner to make it wider or narrower: the text and logos grow and shrink with the width (between 220 and 640 pixels wide), and the height always fits the games. It remembers its spot and its size and reopens the same way. The ✕ hides it, and clicking its name opens SportsChud. With nothing live it shows "No live games" and your next game, or turn on **Autohide Mini scoreboard** (under Autohide in Settings) so it only appears while one of your teams is playing. It closes along with the app.
- **Game panel**: click any game on **Scores**, or any finished game on **Recaps** (or focus it and press Enter), to open it in place of the list. On Recaps the buttons on the card (Stats, Recap videos) still work on their own, and **← Recaps** takes you back. The top shows the teams, the live score, the period and clock, where it's on TV, and a line score by period, inning or quarter. Three tabs below: **Summary** (team stats in a narrow column on the left, such as shots or rebounds, and the scoring summary with the running score taking the wider right side; in a narrow window they stack), **Box score** (player stats by group, with totals) and **Plays** (the 30 most recent plays, newest first, scoring plays highlighted). While the game is live it refreshes every 15 seconds on its own, keeps your scroll position and open tab, and shows the last update if a refresh fails. It doesn't poll while SportsChud is hidden in the tray, and it stops asking once a game is final. **← Scores** / **← Recaps**, Esc, or any other tab takes you back, and **Open on ESPN** opens the full page. ESPN doesn't publish every section for every sport or game; a section it has nothing for just says so.
- **Win probability** and **Game leaders** are on the Summary tab of the game panel. Win probability is a bar with each team's chance, and once the game has plays, a line showing the home team's chance over the game; before the game it shows ESPN's pre-game projection. Game leaders lists each team's top performers (goals and assists, points and rebounds, passing and rushing yards ...); before the game it shows season leaders. ESPN doesn't provide either for every sport or game; if it has nothing, that block is left out.
- **Pickups** (sidebar) lists recent trades, signings, waivers and call-ups for a league, newest first, grouped by day with a tag for the kind of move. **My teams / Whole league** switches between your teams and everyone; your teams are highlighted. ESPN has no feed for college football, so NCAAF isn't listed. Like Standings and Injuries, only sports where you follow a team show up, and Autohide applies.
- **Leaders** (sidebar) shows the season's top ten in each stat category for a league (the categories come from ESPN, so each sport gets its own: goals, assists, points, saves, passing yards, home runs and so on). Pick the league on the left and the category beside it; players on teams you follow are highlighted and a name opens their ESPN page. Early in a season, or if ESPN hasn't published the new season yet, it falls back to last season's numbers.
- **Scoring** alerts say who scored, not just that the score changed: the first line is ESPN's description of the play (for example the goal scorer and assists in hockey, or the passer and receiver on a touchdown), and the score and period are on the line below. SportsChud asks ESPN for the play details when the score changes and tries up to three times over about 10 seconds if ESPN's play list is slow to update; if it still has nothing, you get the same plain alert as before, so an alert is never lost. If two scores land between checks, the last few plays are listed. An alert for the period ending or the game finishing waits behind a scoring alert for the same game, so "Final" never arrives before the last goal.
- NBA games report at each quarter break and at the final instead of every basket.
- The app polls ESPN's public scoreboard feed (every 15s when a game is live, 60s otherwise) and sends Windows toast notifications when something changes.
- SportsChud must be running to send alerts. By default closing the window hides it to the tray and it keeps running; quit from the tray icon. Turn off **Keep running in tray** in Settings if you want closing the window to quit.

## Recaps
Recaps shows the last 3 finished games for each team you follow (looking back up to 35 days, so weekly sports with a bye still fill up). **By status** shows those same games in one list.

## Recap videos
The **Recap videos** button opens the league's official YouTube channel (`@NHL`, `@NBA`, `@MLB`, `@NFL`; NCAAF uses a general YouTube search) searched for the team you follow plus the game date (e.g. `Maple Leafs Oct 6, 2026`), so that game's video comes first. **Stats** opens ESPN's recap and box score.

## Notes
- The ESPN feed is unofficial and undocumented, so it could change without notice. All feed access lives in `leagues.js` and `engine.js`.
- Add leagues by adding an entry to `leagues.js`.
